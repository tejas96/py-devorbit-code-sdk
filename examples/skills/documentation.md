# Documentation Skill

I will help create comprehensive documentation for your codebase. Here's what I can help with:

## Code Documentation

### Docstrings/Comments
- Write clear, concise docstrings for functions, classes, and modules
- Follow language-specific documentation standards (e.g., Google style, NumPy style for Python)
- Include parameter descriptions, return values, and examples
- Document exceptions and error conditions
- Add inline comments for complex logic

### API Documentation
- Document public APIs and interfaces
- Provide usage examples
- Explain parameters, return values, and side effects
- Include version information and deprecation notices

## Project Documentation

### README
- Project overview and purpose
- Installation instructions
- Quick start guide
- Basic usage examples
- Link to detailed documentation

### Contributing Guide
- How to set up development environment
- Coding standards and style guide
- Testing requirements
- Pull request process

### Architecture Documentation
- System architecture overview
- Component diagrams
- Data flow descriptions
- Design decisions and rationale

### User Guide
- Step-by-step tutorials
- Feature explanations
- Common use cases
- Troubleshooting tips

## Documentation Best Practices
- Keep documentation close to code
- Update docs when code changes
- Use examples and code snippets
- Make it easy to search and navigate
- Include visual aids (diagrams, screenshots) when helpful

Please let me know what you'd like documented, and I'll create appropriate documentation for it.
