# Debug Assistant Skill

I will help you debug the issue you're encountering. Here's my systematic approach:

## 1. Understand the Problem
- What error message or unexpected behavior are you seeing?
- When does the issue occur?
- What were you trying to accomplish?

## 2. Analyze the Error
- Examine the error message and stack trace
- Identify the file and line number where the error occurs
- Understand the context of the failing code

## 3. Investigate the Code
- Read the relevant source files
- Check variable values and data flow
- Look for edge cases or unexpected inputs
- Review recent changes that might have introduced the issue

## 4. Reproduce the Issue
- Create a minimal reproducible example
- Identify the exact steps to trigger the error
- Isolate the problematic code

## 5. Suggest Solutions
- Propose specific fixes with code examples
- Explain why the fix works
- Suggest preventive measures to avoid similar issues

## 6. Verification
- Help verify the fix works correctly
- Ensure no new issues are introduced
- Recommend adding tests to prevent regression

Let me know the error or issue you're facing, and I'll help you debug it step by step.
