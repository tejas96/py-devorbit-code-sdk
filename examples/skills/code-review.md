# Code Review Skill

Please perform a comprehensive code review of the specified files. Focus on:

## Code Quality
- Check for code smells and anti-patterns
- Verify adherence to language-specific best practices
- Look for potential bugs or logical errors
- Assess code readability and maintainability

## Security
- Identify potential security vulnerabilities
- Check for SQL injection, XSS, and other OWASP Top 10 issues
- Verify proper input validation and sanitization
- Review authentication and authorization logic

## Performance
- Look for performance bottlenecks
- Check for inefficient algorithms or data structures
- Identify unnecessary computations or redundant operations

## Testing
- Verify adequate test coverage
- Check for edge cases and error handling
- Ensure tests are meaningful and not just for coverage

## Documentation
- Verify code is well-documented
- Check for clear and helpful comments
- Ensure function/method signatures are self-explanatory

Please provide specific feedback with file paths and line numbers where applicable.
