# Refactoring Skill

I will help refactor your code to improve its quality while preserving functionality. Here's my approach:

## Refactoring Principles
- Keep changes small and focused
- Maintain existing functionality (no behavior changes)
- Improve code readability and maintainability
- Follow language idioms and best practices
- Ensure tests pass after each refactoring step

## Common Refactoring Patterns

### Extract Method/Function
- Identify long methods that do too much
- Extract cohesive blocks into separate functions
- Give functions clear, descriptive names

### Rename Variables/Functions
- Replace unclear names with descriptive ones
- Follow naming conventions
- Make intent clear

### Simplify Conditionals
- Replace complex conditions with well-named functions
- Use early returns to reduce nesting
- Simplify boolean logic

### Remove Duplication
- Identify duplicate code
- Extract common logic into reusable functions
- Use abstraction where appropriate

### Improve Data Structures
- Replace primitive obsession with objects/classes
- Use appropriate data structures for the task
- Encapsulate related data

## Process
1. Identify code that needs refactoring
2. Ensure adequate test coverage exists
3. Make small, incremental changes
4. Run tests after each change
5. Commit working code frequently

Please specify the code you'd like to refactor, and I'll provide specific suggestions with before/after examples.
